Chapter 01

The DOM: A Tree of Objects

The HTML you write is just text. The moment the browser loads it, it becomes a live tree of JS objects in memory — the DOM — and that tree is what you actually read and manipulate.

Fun fact: "View Source" lies to you

View Source shows the original HTML file. DevTools' Elements panel shows the LIVE DOM — after JS has changed it. Once a script runs, these two can look completely different.

Gotcha: innerHTML is dangerous with user input

innerHTML parses your string as real HTML. If that string ever comes from a user, that's how you get XSS. Default to textContent unless you truly need markup.
