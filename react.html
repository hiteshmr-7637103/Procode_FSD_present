Chapter 02

JSX Is Just JavaScript

JSX isn't a new language — it's sugar that compiles to plain React.createElement(...) calls. The curly braces {'{'}...{'}'} just drop back into real JavaScript.

What you write

<h3>Hi, {'{'}name{'}'}</h3>

    Chapter 03
    
The Virtual DOM

    
React keeps its own lightweight copy of the tree in memory. When state changes, it builds a new virtual tree, diffs it against the old one, and only patches the real DOM where something actually changed.

Hooks: useState & useEffect

    
A Hook is a special function (always starts with use) that lets a plain function component tap into React features it couldn't otherwise have.

  

  

    

      
useState

      
Gives a component memory — a value that survives across re-renders.

    

    
+

    

      
useEffect

    Chapter 09 · Centerpiece
    
Lists, Keys & Reconciliation

    Chapter 10
    
Lifting State Up

    
When a piece of data needs to be shared, move the state to the closest common parent — data flows down as props, change-requests flow up as functions.
