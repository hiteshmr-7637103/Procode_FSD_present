Gotcha: money as integers

Notice prices are stored as priceCents (whole integers), not 4.99 as a float. 0.1 + 0.2 !== 0.3 in JS — floating point can't represent most decimals exactly. Store money as integer cents/paise, divide only for display.

Chapter 05 · Closing

The Sync Problem

The cart count now needs to show in two places — a header badge and the cart panel. One data change, two DOM updates required, and nothing stops you from forgetting one.

Load the broken version and click "+ Add Item" a few times — the cart panel grows correctly, but the badge count silently goes stale. Switch to the correct version — same bug, fixed only by remembering, by hand, every single time.

This is the whole pitch for React
